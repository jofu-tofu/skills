# Measurement scope

Version: MD-M v0.1. The owner approved this checking approach on 2026-11-04. Instrument qualification is bounded and distinct from performance of the conversion skill. Follow [MD-O v0.1](Outcomes.md).

| Outcome | Evidence to collect | Important limit |
|---|---|---|
| MD-O01 | Compare source content and relationships with output paragraphs, headings/lists, table associations, live links and diagram meaning. | Text presence alone misses wrong relationships, invented additions and visual meaning. |
| MD-O02 | Inspect rendered pages and the actual Word view where needed for legibility, clipping and overlaps. | Appearance in one viewer does not establish compatibility everywhere. |
| MD-O03 | Open a disposable copy in Word, edit a paragraph and table cell, save, close and reopen. | Package inspection alone cannot demonstrate editing; automation does not measure human usability. |
| MD-O04 | Compare requested/actual paths, account for batch members, and check preserved source/unrelated files. | Static examples cannot qualify conversion delivery behavior. |
| MD-O05 | Compare the user's completion report with actual stage events, including partial failure and open-only failure. | Truthful reporting of a failed conversion does not make that conversion successful. |
| MD-O06 | Record necessary repairs, questions, interventions and elapsed time alongside correct completion. | A faster wrong result is not better; no universal cost/quality weighting is accepted. |

Use pass for supported compliance, fail for an observed contradiction and unverified for missing or disputed evidence. Record non-applicable features explicitly. Preserve all batch members and failures. Never combine these dimensions into a score that conceals a required failure.

## Development evidence and limits

The first six human-reviewed examples contain a reference, missing paragraph, wrong table associations, clipped diagram, page image and valid typography alternative. Source-derived native-content checks, actual Word edit/save/reopen and unblinded visual judgment distinguished the four defects and accepted both good examples. This qualifies only that combined diagnostic exercise on those known cases, not arbitrary document fidelity or autonomous visual grading. The evidence belongs to a separate improvement attempt, not routine conversion context.

The native text checker does not yet cover arbitrary added content, all list-order changes or semantic styles. Table checks cover one simple table. MD-O04–MD-O06 remain unverified. No current-skill conversion baseline, behavioral revision or fresh confirmation has been run. The examples were constructed directly, not generated by this skill.

The [attempt index](../Improvements/Index.md) links the portable fixtures, checks, observations and report. Load that evidence when assessing or revising a measure; routine conversions need not load it.
