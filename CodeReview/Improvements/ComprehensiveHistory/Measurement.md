## Decisions and efficient iteration

Score each declared outcome/check pass, fail or unverified with exact observations and evidence. Keep targeted benefit and preservation separate. All required parent checks need applicable qualified evidence; one aggregate case rate cannot erase a failed/unverified outcome. Structural consistency is checked directly against the baseline findings and affected callers; it does not establish downstream behavior by itself.

Run the frozen baseline once. Coherently repair confirmed instruction contradictions and observed failures, review design, then execute affected subjects and required controls. Reuse unchanged qualified artifacts by hash and scope. Verifier-only revisions can reuse frozen upstream outputs; changes to shared producer rules require affected lens and downstream execution. Never repeat an unchanged successful run merely to obtain a preferred verdict. Keep errors, failed candidates, scoring corrections and ties. Amend criteria/reference versions explicitly and regrade both configurations if a genuine checker defect is found.

The final parent assessment maps every outcome to actual case judgments/native/structural evidence, preserves missing coverage, and runs SkillForge's completion checker. A retain decision plus unresolved required work means continue. Complete means this reviewed historical diagnostic task's supported outcomes are evidenced; general production accuracy, repeatability, human comprehension, cost savings, every language and every external environment remain separate claims.
