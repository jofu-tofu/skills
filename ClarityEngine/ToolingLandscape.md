# Tooling Landscape

Use installed specialist skills and current capability discovery first. This file is a reference index, not an assertion that a package or command is installed or current.

## Implementation References

- [Mermaid](https://mermaid.js.org/) — diagram syntax when diagrams improve comprehension.
- [PptxGenJS](https://gitbrent.github.io/PptxGenJS/) and [python-pptx](https://python-pptx.readthedocs.io/) — possible PPTX tooling when the selected specialist workflow calls for it.
- [Marp CLI](https://github.com/marp-team/marp-cli) — possible Markdown slide conversion; verify editability and fidelity against the request.

Verify official documentation and installed capabilities before relying on a command, export feature, or dependency version. Select tooling from the requested outcome, template, and editability requirements. Prefer semantic HTML with self-contained CSS/assets for portable reports; disclose and test any network dependencies.

## Skill Design References

- [Anthropic doc-coauthoring](https://github.com/anthropics/skills/blob/main/skills/doc-coauthoring/SKILL.md) — reader testing from the artifact without the author's context.
- [Anthropic skill-creator](https://github.com/anthropics/skills/blob/main/skills/skill-creator/SKILL.md) — matched old/new evaluations and blind comparisons.
- [Impeccable critique](https://github.com/pbakaus/impeccable/blob/main/skill/reference/critique.md) — independent judgment reconciled with technical evidence.
- [Anthropic PPTX](https://github.com/anthropics/skills/blob/main/skills/pptx/SKILL.md) — file and rendered-output inspection.

These are sources of mechanisms, not instructions to import another environment's paths, commands, or approval policies.
