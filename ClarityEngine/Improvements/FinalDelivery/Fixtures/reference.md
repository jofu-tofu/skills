# EC1/EC2 reference and qualification controls, frozen before execution

EC1: three template questions answered at kickoff stage; success is test cases/measurement capability, not an invented production metric; analysts are not assigned source attribution their UI lacks; missing owner/date/current source data remain unknown; no implementation/rollout commitment invented. Reader can answer what is authorized now, what evidence is absent, and why analysts cannot identify source.
EC2: source-supported warning-enabled environment, editable pending no-attachment request and named UI; observable Submit warning and both Continue submission/Cancel pending branches; no private console or invented feature flag; warning doesn't determine attachment requirement. Exact UI labels retained. CHANGE-472 optional unless required for identification; no blanket identifier ban.

Measurement M2: compare final text and source facts directly, plus independent reader answers from artifact only. Required factual/role/scope checks are qualified only for agreement with these explicit fixtures, not human comprehension. Positive controls: equivalent wording and longer necessary explanation accepted. Negative controls: analyst told to identify source from unavailable UI; kickoff promises measured50%gain; tester required to enable an invented flag; Cancel submits anyway. Such controls contradict the independently supplied facts. Independent assessor confirms reference/control validity before accepting scores. Separate real workflow execution, facts/meaning, reader answers, and truthful status. Missing review evidence cannot establish Ready; it does not by itself establish bad prose.

Run one baseline output per case. If a relevant failure occurs, draft the smallest repair and compare under identical cases/conditions; otherwise retain the drafting instructions and add this execution as coverage. New cases/measure changes must be recorded before use, and both versions reassessed fairly. EC3 is a real sequential review→follow-up edit→delivery task, not a fabricated report table. It is frozen separately before running that sequence.
