# Gap record template

Status: template, not observed evidence. Store with the target's attempt or assessment records; link it from the relevant index so later sessions need no chat history. Reserved answer keys remain outside routine context.

| Field | Record |
|---|---|
| Identity and scope | Gap ID/date; target/version/workflow; assessment, design or edit scope. |
| Incident | Input, actual behavior, context and evidence links; mark historical, synthetic or not reproduced. |
| Expectation | Expected behavior, source/authority, affected outcome IDs and consequence. |
| Current measurement | Measure/checker/case-set IDs and versions; would it detect this incident? Evidence or unknown. |
| Diagnosis | Skill, outcome, benchmark coverage, checker, environment/evidence, or mixed; alternatives and confidence basis. |
| Response | Keep measure, add cases/stratum, revise checker, clarify outcome, revise skill, or defer; rationale. |
| Measurement change | Old/new definition, reference provenance, qualification status; preserve old results and rescore both versions fairly. |
| Next check | Competing predictions, smallest useful experiment, budget, protected behavior and fresh cases needed. |
| Continuity | Linked plan/results/decision; retained version if decided; unresolved items and next-session entry point. |

Owner: [DiagnoseGap](../../Procedures/DiagnoseGap.md). Handoff: [PlanChange](../../Procedures/PlanChange.md) or assessment through EvaluateSkill, then [RecordLearning](../../Procedures/RecordLearning.md).
