## Implementation decision (recorded after drafting; based on pre-draft traces)

The bundled CLI 0.167.0-alpha.3.2 runs the configured model. Four synthetic native runs completed: two direct successful PowerShell skill reads, two successful tasks with no tool events. Choose option 2, an offline exact-read observer. It cannot establish negative selection or hidden native selection events; preserve unverified fields. Direct command form plus complete matching file content and frozen identity are required. No skill description or procedure repair is justified: no trigger failure was demonstrated.

Case consolidation: share fixture registration and offline parsing, but keep native sessions independent because shared context would preload a skill and invalidate discovery. No further model repetition is needed for a deterministic parser claim. New extraction code is tested against these captured observations and controlled misleading streams; this is qualification data, not a held-out description comparison.

Primary source records: landscape-keyword entries 4 and 5 (Jiang/Skill-Use) support separating discovery and outcome, with partial-method/preprint limits. No academic magnitude is used as a local acceptance threshold.
