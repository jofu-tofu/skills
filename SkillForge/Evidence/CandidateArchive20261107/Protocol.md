# Candidate archive investigation protocol

Frozen 2026-11-07 after initial discovery, before any new execution or runtime edit. Baseline e91db4fedf75264cf0113be0f7adf7180b97b6de; branch codex/skillforge-candidate-archive-20261107. Initial inspection already exposed historical outcomes; none can be fresh confirmation.

Scope: determine whether a real stalled improvement has complementary candidates current execution fails to exploit. Implement and evaluate bounded ancestor selection only when local evidence supports that mechanism. Own candidate history/selection support; PlanChange remains policy owner. No integration, installation or other-skill changes.

Existing criteria: U03 baseline identity, U04 recoverable alternatives, U07 discriminating experiment, U10 total effort, S02 preservation, S05 evidence scope, S06 justified no change. Contribution map: RecordLearning preserves attempts; GenerateAlternatives exposes mechanisms; PlanChange selects and owns budget/preflight; ApproveSkill decides. No missing owner is assumed.

Discovery decision: inspect the historical archive replay and its inputs, actual opposing renderer workloads and their follow-up, rejected retrieval/efficiency alternatives, recent independent measurement authors, and latest unresolved-session findings. Qualify historical interpretation by exact source excerpts/hashes and cross-checking the replay vectors against original input. Controls: complementary vectors must not imply an observed selection failure; differing workload priorities must not imply a global winner; an actual trace showing discarded useful alternatives would warrant a trial even if storage exists. Historical aggregate winner is illustrative, not actual baseline behavior.

Proceed only if an actual available candidate pair addresses different relevant requirements AND a current ordinary execution leaves a consequential selection opportunity. Storage alone does not establish use, but complementary scores alone do not establish failed use. No exhaustive absence or reliability claim.

If headroom exists, freeze a second protocol before trials: same starting archive/evidence, author and candidate-generation mechanism, total preparation/generation/selection/scoring/confirmation allowance, protected gates and independent fresh cases. Inspect the first naturally selected ancestors; identical inputs stop the mechanism comparison. Charge selection work to the same total budget. No forced greedy baseline or confirmation reuse. The specific budget must follow the discovered task; no invented trials now.

If no supported opportunity survives the above checks, retain baseline with a source-backed inventory and runtime identity verification. Do not rerun saturated cases or create a synthetic stall. Existing executed evidence may support the bounded no-change decision; it is not a new method-effectiveness trial. Preserve all historical failures/ties. Initial discovery is not preregistered evidence.

Cost: this discovery uses local source inspection and one deterministic integrity audit; no external model sessions, candidate generation, selection scoring or confirmation runs unless the proceed condition is met. Record actual calls/results and unknown overall cost without claiming savings. Revisit only on a new real selection trace or new task priorities. All required feasible checks above precede closure.
