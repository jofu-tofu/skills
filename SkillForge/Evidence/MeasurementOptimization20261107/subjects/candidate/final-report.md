# Renderer optimization decision

Retain target/Tools/RenderTemplate.ts. Median supplied-benchmark time fell from 2156.4 ms to 267.8 ms (87.6% lower, 8.05x throughput for this fixed batch). Each of 240 outputs per run matched exactly. Three alternating serial trials per version; raw times: timings.json. Warm measured compile calls fell from 480 to 0.

Implementation: a bounded LRU cache reuses compiled parent/partial functions after exact source comparison. Parents are reread each render. Local partial names are rediscovered and registered every render, but their sources are read only when invoked, including dynamic and nested use. No data or rendered-output cache, filesystem metadata assumptions, new dependencies, or public interface changes. Cache holds at most 256 entries / 4 Mi source characters; compiled-function memory not measured.

Preservation: original 37 tests pass on both copies (95 assertions each). Added consumer suite passes 26 checks per version for both overloads, restored-mtime same-size edits, delete/recreate/replacement, dynamic/nested partials, registry/helper replacement, malformed-source recovery, live JSON/YAML/object data, and CLI stdout/preview/file output. Additional 274 checks per version cover partial blocks, inline overrides, indentation, and eviction after 270 distinct parents. Evidence files are listed in decision.json.

Qualification and failures: content-only cache eliminated compile calls but exploratory timing barely changed (2135.6459 versus 2129.879 ms). Metadata caching achieved only about 7.4% median improvement and failed the frozen 10% threshold; metadata-timings.json retains all runs. A script replacement missed CRLF lines and produced ReferenceError: compileSource is not defined; fixed before valid evaluation (edit-failure.txt). Edge suite v1 incorrectly expected standalone indentation despite trailing text; both baseline and candidate failed identically. Original script/logs remain; v2 corrected the expectation and reran both. No failure was discarded.

ReviewDesign: reviewed renderer entry points, cache ownership, local partial lifecycle, data loading, CLI and validator consumers. No blocking documented-contract regression found. Lazy loading intentionally defers errors from unreadable unused partials; an unrelated render now succeeds where eager loading would fail. This is an incidental behavior change, explicitly accepted under the documented contract. Used sources are still read fresh and their errors propagate. Cache eviction affects performance only. Source count limits prevent unbounded entry accumulation.

Measurement scope: exact output and API assertions support these finite deterministic contracts. Direct elapsed timing supports this workload on this host, not a universal speed guarantee. The test author and evaluator are the same agent; no independent hidden assessment was supplied. No downstream model quality claim. No cold CLI speed claim. Concurrent file mutations are not an atomic snapshot.
