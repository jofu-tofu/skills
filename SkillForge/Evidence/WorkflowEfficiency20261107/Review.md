# Candidate review and measurement scope

Separate operator pass before interpreting outcomes. Reviewed UpdateSkill's
reference list, scope table, improvement loop and caller handoffs against
ReviewDesign RD1–RD5 and Authoring. The added paragraph changes acquisition of
instructions, not their authority. Reuse requires complete unchanged content;
truncation, context loss, edits and scope changes invalidate reuse. Existing
machine contracts, qualification and completion remain explicit. No blocking
contradiction found. Risk: an executor may mistakenly treat unavailable content
as retained or defer a needed dependency. Actual traces and external outcomes
must assess that risk; a static pass is insufficient.

Measurement qualification is in raw qualification.json. Ledger references derive
from the historical target Intent and independently calculated small exact sums,
not author assertions. Five controls cover original, valid alternative, wrong
signed sum, swallowed error and an irrelevant comment. Instrumentation observes
two versus one input reads; actual CLI execution separately checks the result.
Prompting reuses the unchanged external consumer checker with its prior passing
original/two cache implementations and rejected stale-output mutant. Scope is
these executable contracts only, not open-ended semantic validity.

Cost observations are separate units. Process elapsed includes local and service
delays; usage includes repeated/cached context. Returned bytes exclude internal
reasoning and cannot establish token savings. Command mentions of procedure names
are trace-navigation aids: inspect actual commands before calling them reads.
Do not infer non-use merely because a literal path is absent from a command.

Setup failures preserved: the first structural invocation supplied a path where
the legacy tool expects a skill name. Two corrected sandbox invocations still
lost the SKILLS_DIR environment setting and searched the default inaccessible
directory. Normal scoped escalation retained the required setting and produced
14/14 structural passes. These are harness setup failures, not target outcomes.
The 34 existing completion-checker tests pass. No new behavioral conclusion follows
from either mechanical suite.
