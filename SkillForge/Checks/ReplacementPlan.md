# Replacement qualification plan

Historical replacement plan; its blanket not_executed label predates v0.7–v0.9. Current scoped results and release qualification are in [ValidationSummary](../Evidence/ValidationSummary.md). Compare the installed baseline and draft in isolated disposable targets, same requests, runtimes, tools, and budgets. Freeze versions and independently review expected outcomes before runs.

| Case | Expected behavior |
|---|---|
| Create a new skill | Coherent candidate, intent, useful entry points, structural checks, honest evidence limits. |
| Fix a typo | Direct scoped edit and proportional checks; no mandatory full quality-document rewrite. |
| Review without editing | Prioritized evidenced findings; target unchanged. |
| Construct cases only | Reusable frozen suite, not_executed, no model task runs. |
| Fix a behavioral failure | Reproduce where possible, preserve baseline, repair and regression checks, scoped decision. |
| Integrate research | Traceable implication and limitations; preserve purpose. |
| Refactor workflows | Preserve routing and intent, verify references and affected handoffs. |
| Diagnose triggering | Native-runtime check or explicit unsupported status; no command-discovery result mislabeled as native selection. |
| Missing evidence | No unsupported approval; useful next check. |

Measure task success, protected behavior, unsupported claims, files loaded, time/tokens, and human correction effort. Score workflow outcomes separately before assessing the combined lifecycle.
