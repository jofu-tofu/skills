# Outcomes — UpdateSkill

These proposed requirements specialize [Shared](../Shared.md); do not score document count or wording similarity as usefulness.

- **U01:** The revision addresses the requested change or declared failure.
- **U02:** Mandatory behavior and affected shared dependencies remain protected.
- **U03:** A behavioral improvement claim compares the candidate with the preserved baseline.
- **U04:** The next run can recover applicable criteria, changed assumptions, and the retained version.
- **U05:** A reported gap has an evidence-linked diagnosis distinguishing skill behavior, outcome, benchmark coverage, checker and missing evidence; changes target the justified cause, including a no-skill-edit result.

Origin: workflow outcome and shared commitments, operationalized here as draft checks. Validate these checks before using them as authoritative references. Revisit when they miss failures or reject valid alternatives.
