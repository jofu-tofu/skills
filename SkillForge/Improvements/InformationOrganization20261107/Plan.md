## Outcome and first principles

The job is to find applicable current instructions and evidence, act correctly, and maintain their owners with less unnecessary reading. Files and folders are means, not outcomes.

Facts: three user workflows already own execution; procedures own shared operations; current quality profiles and historical ImproveSkill coexist; Architecture repeats several procedural summaries. These constraints are binding instructions, not physical laws. Design choices: directory names, architectural prose, optional links. Untested assumptions: a task-oriented owner map will save reading; agents will use it; less reading will preserve decisions. No observed general navigation failure is claimed.

## Alternatives and selection

| Mechanism | Benefit hypothesis | Risk / distinguishing observation |
|---|---|---|
| Keep baseline/search | No new maintenance surface | Baseline may already find owners cheaply; matched lookup evidence can reject change |
| Move archival trees | Search excludes obsolete profiles | Breaks paths and overlaps history-retrieval track; disproportionate before observing archive confusion |
| Add universal loader/tool | Automated dependency selection | Adds runtime/dependency burden and repeats workflow policy; unnecessary for present experiment |
| Replace Architecture summaries with optional task-to-owner map | Direct owner discovery, less repeated policy, same stable paths | Map can drift or be ignored; inspect exposure, exact owners, actual read bytes and actions |

Select last option; no new folder convention, mandatory stage or owner policy. SKILL's architecture link names owner/loading use. Preserve architectural separation and archival boundaries. Keep version/release metadata unchanged until a disposition.

## Frozen experiment and measurement v1

One fresh agent per arm, three real maintainer decisions plus an actual typo edit, same prompts and snapshot contents except two runtime files. Agents begin at SKILL.md, choose reads/searches through a logging reader, and produce cited decisions plus a changed tiny target. They do not see this plan or reference key. Cases are source-grounded diagnostic tasks, not unseen population samples; multiple tasks share each arm's context. Same inherited model/settings, no requested model override. Costs: cumulative returned UTF-8 bytes and read/search calls; runtime and billing tokens unknown. Logging wrapper adds matched scaffolding; not normal-tool causal proof.

Tasks: (1) route a structural loading revision and a fixed rename/typo, identify where trigger policy is maintained; (2) decide current quality ownership and what qualified measurement plus an unverified required result permits, with readiness/completion owners and executable format; (3) locate current validation limits versus historical observations, and fix one supplied typo without an improvement programme. Answers must enable the subsequent maintainer to act correctly; merely naming files fails. Target edit must change only `teh` to `the`.

Reference basis: existing PlanChange activation section, Update scope table, Architecture ownership, DesignMeasurement qualification states, ApproveSkill completion table, completion template, ValidationSummary integration and unsupported claims. Independent source contracts, not candidate prose, ground labels. Manual semantic checking with quoted source support; accept equivalent correct formulations and additional relevant citations. Qualify on positive, valid alternative, misleading shorter answer (qualified implies ready), historical-profile answer and missing evidence. Cost reader checked on known file bytes and repeat reads; smaller output alone cannot pass quality gate. Novel ambiguity is adjudicated, not auto-failed.

Acceptance: all mandatory case decisions and exact edit pass, links resolve, no current rule lost or moved to history; candidate must be exposed and lower aggregate returned bytes without increasing calls to support this bounded navigation-effort gain. Otherwise retain baseline, preserving the tested candidate in commits. No population advantage, latency or end-to-end skill-authoring quality claim. A follow-up is justified only by a concrete correctable failure or exposure gap; freeze amendment first, do not repeat ties to seek a win. No more than one correction round in this initial iteration unless a newly found required regression needs resolution.

Behavioral preservation covers structural versus mechanical/typo scope, active versus historical profiles, measurement versus readiness, task completion versus candidate retention, optional evidence, and actual minimal edit.
