# Context outcomes and coverage

Context should give the next agent the right grounded instructions at the right scope. Required families are intent/host routing, full Generate, targeted dependencies, source-aware Audit, content-only Prune, read-only Drift, and mode-correct agent handoffs. Generated file count, shortness and JSON parse success are supporting checks, not the purpose.

- **C-PRUNE:** Remove expendable content without losing global inheritance, local exceptions, necessary commands, intentional delegation or maintenance metadata. A sibling consumer must still receive global rules.
- **C-AUDIT:** Correct grounded stale claims, retain accurate constraints and delegated authority, and distinguish missing evidence from proven error.
- **C-HANDOFF:** Dispatch, validation, retry and synthesis agree on the calling mode's output schema; partial coverage remains visible.

Bounded matched audit/prune trials preserved a root global policy, auth-local rule, delegated document and production files while correcting a stale command. Later targeted Generate and lifecycle trials extend this initial evidence; current per-outcome judgments below take precedence. See [scope and schema attempt](../Improvements/ScopeAndSchemas.md).
